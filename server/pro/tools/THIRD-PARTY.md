# 媒体处理工具来源

- FFmpeg 7.1 Windows x64 essentials，构建标识 `7.1-essentials_build-www.gyan.dev`。
- 来源：imageio-ffmpeg 0.6.0 的 Windows wheel 中原样附带的二进制。
- FFmpeg 许可证：GNU GPL v3 或更新版本，见 `FFmpeg-LICENSE.txt` 与 https://www.gnu.org/licenses/gpl-3.0.html 。
- FFmpeg 对应版本源码：https://github.com/FFmpeg/FFmpeg/tree/n7.1 。
- 构建提供者及构建资料：https://www.gyan.dev/ffmpeg/builds/ 。
- imageio-ffmpeg 项目：https://github.com/imageio/imageio-ffmpeg/tree/v0.6.0 ，封装许可证见 `imageio-ffmpeg-LICENSE.txt`。

系统通过独立子进程调用 FFmpeg。这里没有修改 FFmpeg 程序。
