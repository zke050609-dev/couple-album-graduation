# 本地图像搜索测试记录

测试日期：2026-10-14。

模型：[OFA-Sys/chinese-clip-vit-large-patch14-336px](https://huggingface.co/OFA-Sys/chinese-clip-vit-large-patch14-336px)。硬件：NVIDIA GeForce RTX 5060，8 GB 显存。运行环境：PyTorch 2.10.0 + CUDA 12.8，Transformers 4.57.6，GPU FP16。

公开素材来自 scikit-image 0.26.0 自带样例，没有使用私人照片。它们在测试相册中采用匿名文件名，照片描述不含搜索词。

|---|---|---|

| 咖啡 | coffee（咖啡） | 是 |

本小样本 Top-1 为 6/6。这不是通用识别准确率，不能代替大规模标注集评估。

模型载入约 0.86 秒，首张图片编码约 14.41 秒，后续图片平均编码约 0.031 秒。这里记录编码耗时，不包括 HTTP 上传、媒体预处理、任务排队和页面渲染。

完整 API 测试在标准阈值 0.28 下六个查询均返回对应图片，原文字检索均没有相同文字命中。还验证了未登录拒绝、其他空间拒绝、访客查询及重建拒绝、图片详情、关键词模式和手机页面。测试账户与照片位于独立临时数据库，未导入正式相册。
