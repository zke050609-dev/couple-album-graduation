# 答辩演示流程（约 8–10 分钟）

准备不同浏览器或隐私窗口，只使用公开或自制素材。

1. 注册甲账号，说明空间初始为空；注册乙账号，展示它默认空间看不到甲的内容。
2. 甲生成协作邀请，乙输入加入；展示成员角色与双人容量限制。
3. 上传带 EXIF 的图片、短视频和同名实况组合；展示原件、后台任务、缩略图、拍摄日期及视频预览。
4. 再传同一文件，展示原件复用；检查相似照片，解释 SHA-256 完全去重与 dHash 相似提示的区别。
5. 乙查看共享更新；两个窗口先后保存编辑内容，展示版本冲突检查。
6. 在描述加入“海边散步”，展示中文搜索、日期/城市筛选和月份地点聚合。
7. 删除相册后从回收站恢复，说明父级快照与引用安全删除。
8. 邀请只读访客，展示浏览正常但修改被后端拒绝；移除后再次访问，展示权限失效。
9. 展示统计、时间分布、原件用量、活动记录与备份导出。
10. 总结认证授权、多空间隔离、并发控制、异步任务、全文检索、感知哈希和数据恢复。

## 常见问题

**为什么用 SQLite？** 本地单节点容易部署，支持事务、WAL、FTS5；扩展时可迁移数据库。

**为什么保留 JavaScript 页面？** 复用已完成的地图和相册交互，将工作重点投入后端与一致性，没有虚称使用 Vue。

**访客能绕过隐藏按钮吗？** 按钮仅是交互限制，所有业务接口和媒体下载都做后端授权。

**同时修改会怎样？** 保存检查版本号，冲突返回 409 并提示同步重试；没有逐字段自动合并。

**相似照片是 AI 吗？** 不是，它使用可解释的 dHash 与汉明距离，存在误报边界，仅供确认。

**是否端到端加密？** 没有；实现的是访问隔离和私有文件路由，不能宣称服务器无法读取原件。

**导出为什么不包含照片字节？** JSON 保存记录和引用，完整迁移要同时备份数据库与媒体目录，避免大文件内嵌。

## AI 回忆助手演示

1. 从足迹地图进入已有照片的城市，点击“AI 写回忆”。
2. 勾选几张照片，查看提取的日期，写下当时的经历与感受。
3. 生成草稿后演示修改标题和正文；先点击“暂不收藏”，说明生成不自动保存。
4. 重新打开助手，点击“放入回忆盒”，展示纸条与关联照片。
5. 展示纸条后续编辑及重复请求不会重复收藏。介绍本地生成、来源校验、角色隔离与版本冲突处理。

## AI 任务与草稿恢复演示

在城市助手填写描述后刷新，展示照片选择和描述恢复；提交生成后离开页面，到“AI任务与草稿”查看状态。生成完成后修改正文，再刷新展示自动保存。用独立测试环境演示生成失败重试、处理中服务重启后重新排队、多页面更新冲突不会静默覆盖。最后点击收藏，展示回忆盒只新增一条。历史完成日期折叠展示，避免任务堆积。
