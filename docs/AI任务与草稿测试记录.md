# AI 任务与自动草稿测试记录

日期：2026-10-15。

所有测试使用独立临时数据库、合成账号和公开咖啡照片或合成照片引用，没有在正式空间添加测试记录。

## 后台任务与自动保存

`tests/memory-workflow.cjs` 使用专用测试入口模拟推理延迟、失败和中断；该入口不被正式服务加载。已验证：

- 生成前照片选择、描述和风格保存；生成后标题、日期和正文保存，服务重启后仍能读取。
- 只允许本人管理当前空间的草稿；协作成员不能读取对方未收藏草稿，访客不能使用草稿和任务接口。
- 每份草稿最多一个活跃任务，请求重试和重复收藏不会重复插入。
- 失败后可重新排队；运行中重启后重新处理并记录恢复次数和尝试次数。
- 生成期间修改草稿，不被新结果覆盖；结果可先查看，再明确采用。
- 生成结果、任务完成状态及文档更新在同一数据库事务提交；旧任务结果不会在重启时重复迁移为新草稿。
- 按北京时间日期分组；25 条历史记录分两页返回，20 + 5，不重不漏。
- 删除未收藏草稿时清理关联任务及未收藏结果；外键检查通过。

## 浏览器交互

通过桌面及 390 × 844 手机尺寸验证：

- 填写描述后立即刷新，最后输入和照片选择可恢复。
- 提交生成后离开页面，后台完成，重新打开可编辑结果；尚未正式收藏时回忆盒没有新增记录。
- 编辑标题正文后刷新可恢复；断网输入本机暂存，恢复连接后同步。
- 两个页面同时编辑时不会静默覆盖；冲突保留本页内容，明确选择后同步。
- 失败任务可以点击重试；处理中服务重启，恢复后可查看完成结果。
- 同一城市可新建另一份草稿，不覆盖已有未收藏内容。
- 历史完成日期默认折叠；桌面和手机页面没有横向溢出，未出现 JavaScript 错误。

## 真实模型验证

额外使用正式服务入口和已安装的 Qwen3-1.7B 执行真实持久化任务，未加载模拟推理入口。

提交请求约 14 ms 返回排队状态；随后观察到模型加载、生成、完成状态。本机约 11.3 秒完成一段 81 字回忆，带入给定日期、景德镇市和喝咖啡、毕业计划等资料，使用 CUDA。此单次样例不代表其他输入和设备的性能保证。

任务完成后笔记数量保持不变，结果停留在个人草稿，需使用者编辑确认再正式收藏。

## 边界

服务关闭时不执行生成，重启后重新排队。已同步草稿在服务器保存，尚未同步的内容依赖当前浏览器本机暂存；清除浏览器数据会清除未同步副本。历史任务状态展示实际阶段，不提供虚构的百分比。新任务草稿保留至用户删除或删除空间，旧同步接口继续兼容原过期策略。
