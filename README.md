# 两个人的回忆档案

面向两人共同记录生活的私密多媒体相册，支持照片与视频管理、城市足迹、时光轴、日记和本地 AI 回忆助手。

## 启动与使用

首次使用请双击 **首次安装.cmd**，确认安装基础环境，再选择是否安装 AI 功能。安装完成后自动打开相册；以后双击 **打开回忆相册.cmd** 即可。网站固定运行在 **http://127.0.0.1:8088**。原来的 `index.html` 入口保留，会检查本地服务并跳转；服务未启动时显示启动提示。重启电脑后再次双击启动文件即可。

第一次请选择“注册账号”。账号为 3–32 位字母、数字或下划线，密码至少 8 位。没有预置账号，首次运行请注册自己的账号。

1. 注册后自动建立独立空间，可在“双人空间”另建空间。
2. 创建者生成邀请码，另一位用户注册后输入，加入共享空间。
3. 创建者和协作成员合计最多两位，另可邀请二十位只读访客。
4. 在“媒体中心”上传照片、视频或同名实况组合，选择已有相册或新建相册。
5. 后台生成缩略图、识别拍摄信息和城市、处理视频预览；带位置照片处理完成后会询问是否同步到对应城市相册，可以逐张勾选或暂不同步。原相册和原件都保留。
6. 媒体与处理任务按上传日期分组：今天、未完成或失败的日期默认展开，历史已完成日期默认折叠；展开后分页加载。
7. 城市相册、时光轴、旅行计划、日记、纪念日等原功能继续使用。
8. 在“双人空间”底部，创建者可删除当前空间，需输入完整名称确认。整个空间及照片原件永久删除，不进入回收站；其他空间不受影响。删除最后一个空间后，可重新创建或加入。正在处理影像时暂不允许删除。
9. 删除内容进入回收站，可恢复到原相册位置。清除回收记录不会删除原件，创建者可以在媒体中心删除未引用原件。

## 主要功能

- 账号登录、密码更新、密码哈希和服务端会话。
- 多空间隔离、双人协作、单次邀请、只读访客和成员管理。
- 内部版本号并发检查，界面只展示同步状态；故事页面每 8 秒检查共享更新，表单编辑期间暂缓替换。
- 独立媒体存储、SHA-256 去重、类型检查、原件配额和私有媒体路由。
- Python/Pillow 缩略图、EXIF 时间/相机/GPS 提取、离线省市识别、dHash 相似照片提示。
- FFmpeg 视频封面、兼容 MP4 预览，以及实况组合浏览。
- 持久化后台任务、失败展示、手动重试和服务重启恢复。
- 中文搜索与筛选、月份/城市聚合、回收恢复、统计、审计、导入导出。
- 打开陌生城市后取消不会留下新足迹，只有包含已上传影像的城市计入访问数。空间概览的相册数量仅计算普通相册；同步影像复用原件且不重复计数。

系统已接入本地 Chinese-CLIP 图像语义模型，照片不发送给外部 AI 服务。

## 图片内容搜索

全局搜索提供“综合搜索”“照片内容”“文字信息”。进入或重新打开搜索页时不显示内容或上次结果，提交关键词或筛选条件后才展示结果；空条件不会自动列出全部记录。输入画面描述，例如“猫”“海边”“夜晚的街道”，即可按图像特征查找相关照片，无需事先填写同样的文字。可以调整匹配要求。内容相似度表示图文相关程度，并非正确率。

照片内容搜索需要安装 Chinese-CLIP ViT-L/14 336px 模型及推理环境。已有及新上传照片自动建立索引，页面展示进度；失败可以点击“补建 / 重试索引”。只搜索当前空间的在用照片，已删除/回收的记录排除，同步副本去重。

模型常驻本机进程，推理离线运行。首次加载和首张图片会有冷启动时间。换电脑后双击“首次安装.cmd”并确认安装 AI 功能，联网下载公开模型和推理依赖；下载阶段不读取照片。模型、环境和向量数据均属于 runtime，不包含在源码包中。

## AI 功能说明

不安装 AI 时，基础相册功能可以正常使用，包括照片管理、日记、时间轴和城市足迹；AI 回忆文案和图像内容搜索功能受限，文字信息搜索仍可使用。视频处理需要基础安装中的 FFmpeg。AI 安装需额外下载数 GB 的依赖和模型，受网络、磁盘空间和电脑性能影响，CPU 推理可能较慢。可随时重新运行首次安装补装 AI 功能。

首次安装适用于 Windows，通过 winget 安装缺少的 Node.js、Python 和 FFmpeg，并通过 pip 安装 Pillow。缺少 winget 时，请先安装 Microsoft 应用安装程序。其他系统请按下面的运行要求手动配置。

## 运行要求

- Node.js >= 22.13，使用内置 SQLite，无需安装 MySQL 或 Node 依赖。
- Python 3.10+ 与 Pillow >= 10。运行 `python -m pip install -r server/pro/requirements.txt`，必要时设置 `PYTHON_PATH`。
- GitHub 源码不附带 FFmpeg。视频处理需自行安装 FFmpeg 并加入 PATH，或用 `FFMPEG_PATH` 指定可执行文件。
- 终端启动可运行 `node start-preview.cjs`，按 Ctrl+C 停止。

环境变量说明见 `server/pro/.env.example`，该文件不会自动加载。

## 数据与备份

运行数据在 `runtime/`，包含 SQLite、原件、缩略图和视频预览，源码包排除该目录、日志、凭据和测试数据。

网页导出含记录和媒体引用，适合恢复同一空间。完整迁移应先停服，再复制整个 `runtime/`。跨空间媒体引用会被拒绝。新安装会创建独立数据库，不附带作者的账号、照片或日记。

服务支持本机和局域网访问。手机与电脑连接同一 Wi-Fi 后，使用启动脚本输出的手机访问地址；地址格式为 http://电脑局域网IP:8088/ 。电脑原地址 http://127.0.0.1:8088 保持可用。更换网络后，重新运行启动脚本查看新的 IP。局域网访问需在运行电脑上配置相应防火墙规则。跨公网访问仍需独立部署、HTTPS、域名和相应环境配置。

## 项目结构与测试

| 路径 | 用途 |
|---|---|
| index.html / 原 JS、CSS | 原相册、地图和故事功能 |
| professional.js / professional.css | 账号、空间、管理页面与 API 接入 |
| server/pro/server.cjs | HTTP API、认证授权、上传和媒体流 |

| server/pro/worker.cjs / media-worker.py | 后台调度与媒体处理 |

运行 `node tests/api.cjs` 、`node tests/location.cjs` 、`node tests/media-workflows.cjs` 、`node tests/semantic.cjs` 和 `node tests/space-delete.cjs`。它启动独立临时服务，创建合成账号后执行验证，结束时停止测试服务，不使用正式 `runtime/`。



## AI 回忆助手

在城市相册中点击“AI 写回忆”，选择 1–12 张照片，填写当时的经历和感受，选择自然日记、温柔纪念或简洁纪实。系统读取当前城市照片的日期、拍摄城市及已有说明，调用本地 Qwen3-1.7B 生成文字草稿。文字模型不读取照片像素，未实现自动看图编写描述。

生成后可以修改标题、纸条日期和正文；只有点击“放入回忆盒”才会收藏。草稿会按当前账号和空间自动保存，照片选择、描述、风格以及编辑后的标题、日期和正文均可在刷新后恢复；网络中断时先在本机暂存，恢复连接后再同步。通过“AI任务与草稿”可以继续编辑或删除未收藏草稿。保存后的纸条保留来源照片、原日期地点和生成来源，原照片继续留在城市相册；纸条仍可编辑、删除和恢复。

创建者和协作成员可生成与收藏，访客只能浏览已收藏的回忆。收藏采用版本冲突检查和幂等确认，重复请求不新增纸条。生成期间被移除成员的请求不会取得草稿；保存前再次验证来源照片。

文字生成需要下载公开模型，推理仅使用本地文件。双击“首次安装.cmd”并确认安装 AI 功能；联网仅用于下载公开权重和依赖，不上传照片或描述。首次生成会加载模型，空闲两分钟后释放文字模型进程。新页面通过持久化后台队列提交生成任务，离开页面不会中止；失败可重试，服务重启后未完成任务重新排队。模型不可用时展示错误，不用模板冒充 AI 生成。

新增测试：`node tests/memory-assistant.cjs`，在独立临时数据库验证城市照片来源、EXIF、权限、冲突、确认收藏、重复保护和过期。

## AI 任务与自动草稿

左侧“AI任务与草稿”提供生成任务和未收藏草稿两个列表，按北京时间日期分组，历史完成日期默认折叠，展开后每页加载 20 项。任务状态包括等待、模型加载、生成、完成、失败。只有自己的草稿和任务会显示，其他协作成员在正式收藏后才能浏览共享回忆。

输入会在短暂停顿后保存到服务器，状态显示“草稿已自动保存”。刷新前尚未同步的输入会暂存到当前浏览器，并在相同账号、空间下继续同步；清除浏览器数据会丢失尚未同步的本机副本。多页面冲突会保留本页输入，供用户选择采用服务器版本或明确保留本页。

服务端任务和生成结果持久化到 SQLite。正在处理的任务在重启时重新排队；结果写入草稿、任务完成状态和关联信息采用同一事务。生成期间草稿有修改时，结果单独保留，需先查看再采用，避免覆盖编辑。收藏仍需明确点击“放入回忆盒”，并验证笔记版本和来源照片。

旧版尚未过期的生成草稿会自动接入新列表；新草稿长期保留到用户删除或删除空间，已收藏记录继续留在回忆盒。旧接口保留兼容，24 小时临时草稿机制仅用于旧的同步生成接口。

新增测试：`node tests/memory-workflow.cjs`。测试入口 `tests/support/memory-server.cjs` 仅供模拟错误和中断，不被正式服务加载；正式任务只调用本机真实文字模型。
